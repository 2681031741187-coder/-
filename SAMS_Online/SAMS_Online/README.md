# SAMS Online

เว็บไซต์ระบบจัดการกิจกรรมในโรงเรียน (SAMS) รุ่นออนไลน์

## เปิดใช้งานในเครื่อง
1. ติดตั้ง Node.js LTS
2. เปิด Terminal ในโฟลเดอร์นี้
3. รัน `npm install`
4. รัน `npm start`
5. เปิด `http://localhost:3000`

ข้อมูลทั้งหมดเก็บใน `data.json` และหน้าเว็บเรียกผ่าน `/api/db` ทำให้เครื่องที่เปิดเว็บผ่านเซิร์ฟเวอร์เดียวกันเห็นข้อมูลชุดเดียวกัน

## เอาขึ้นออนไลน์
สามารถนำโฟลเดอร์นี้ไป deploy บนบริการที่รองรับ Node.js ได้ เช่น Render, Railway หรือ VPS โดยตั้งคำสั่งเริ่มต้นเป็น `npm start` และใช้พอร์ตจากตัวแปร `PORT` ของระบบ

> หมายเหตุ: รุ่นนี้เป็นระบบสาธิต ยังไม่มีระบบบัญชีผู้ใช้/สิทธิ์แบบปลอดภัยสำหรับใช้งานจริงในโรงเรียน
